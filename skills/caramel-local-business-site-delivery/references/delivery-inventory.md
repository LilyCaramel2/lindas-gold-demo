# Complete local-business site delivery inventory

Use this list to avoid an attractive but incomplete handover. Mark each item as complete, pending client input or deliberately out of scope.

| Layer | Required inventory |
|---|---|
| Brand and asset foundation | Approved final logo pack, favicon, palette, typography, image plan, asset register, filename convention, dimensions, transparency status, origin metadata and protected asset list. Complete this before code. |
| Identity | Business name, local positioning and contact facts. |
| Service journey | Homepage, priority service page, secondary service route, decisive CTA, stock/booking disclosure and clear next action. |
| Trust and locality | About/team, exact address, map/directions, genuine Google listing, hours and no invented customer proof. |
| Content | Journal index, article template, matching images, distinct local topic/keyword focus, sharing routes and optional reviewed audio. |
| Languages | Default language, complete reviewed alternate routes, switcher, `hreflang`, translated metadata and language-aware contact/consent/audio. |
| Experience | Mobile-first navigation, light/dark appearance where approved, readable text on images, accessible forms, keyboard focus and reduced motion. |
| Search and sharing | Titles, descriptions, canonical URLs, Open Graph cards, schema, sitemap, robots, manifest, 404 and UTM convention. |
| Privacy and measurement | Privacy route, cookie choice, consent-safe analytics, truthful form behaviour and no GA4 before its ID exists. |
| Release | Review branch, QA record, Lily’s approval message, production merge, live verification and rollback reference. A client preview is optional and is not a release gate unless Lily explicitly makes it one. |
