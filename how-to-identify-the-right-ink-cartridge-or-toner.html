Printer ink in Fish Hoek

Many printers use supplies with similar names. The printer model and cartridge code identify the suitable cartridge or toner. Two printers from the same brand can use different products.

Find the printer model

The printer model is often printed on the front, top or back of the machine. It may include letters and numbers. Take a photo of the full label if it is hard to read.

The model number gives us a starting point. The cartridge code gives us an even better answer.

Find the cartridge or toner code

Inkjet cartridges usually have a code on the cartridge label. Laser printers often have a larger toner code on the cartridge or box. The code can still be read when the cartridge is empty.

Use the access points built into the printer and take a photo of the full label. Keep the printer closed if the cartridge area feels difficult to open.

Use photos to identify the code

Small codes are easy to misread. A zero can look like an O. A one can look like an I. A photograph gives us a clear reference.

Take a photo of the printer model, the empty cartridge or toner box, and any message on the printer screen. For colour printing, photograph both the black and colour cartridges.
